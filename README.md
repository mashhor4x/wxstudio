# STRIMIXA Studio

تطبيق مكتبي لنظام Windows لإنشاء المشاهد وإضافة المصادر، والتسجيل المحلي والبث المباشر، مع أدوات لمؤثرات الكاميرا ومعالجة الصوت.

**الموقع الرسمي والدليل:** https://gamehubx.shop  
**التنزيل:** https://gamehubx.shop/download/latest  
**دليل الاستخدام:** https://gamehubx.shop/document.html

> الإصدار المنشور حاليًا هو 1.2.3. المثبّت المتاح ما زال يحمل اسم WxStudio القديم؛ لم تُبنَ أو تُنشر نسخة مثبّت جديدة باسم STRIMIXA Studio. بعض المؤثرات وعمليات ربط المنصات وميزات البث المتقدمة غير مكتملة أو تعتمد على موصلات غير رسمية قد تتغير. راجع الدليل قبل الاعتماد عليها في بث مهم.

## English

STRIMIXA Studio is a Windows desktop app for arranging scenes and sources, local recording, and live streaming, with camera-effect and audio-processing tools.

**Website and guide:** https://gamehubx.shop  
**Download:** https://gamehubx.shop/download/latest  
**Documentation:** https://gamehubx.shop/document.html

> The currently published version is 1.2.3. Its installer still carries the former WxStudio name; no new STRIMIXA Studio installer has been built or published. Some effects, platform integrations, and advanced streaming features are incomplete or rely on unofficial connectors that may change. Check the documentation before relying on them for an important stream.
